# Vehicle Classification Using YOLOv8

This project implements **vehicle image classification using YOLOv8** and the Ultralytics framework.  
It covers the complete workflow including dataset download, training, evaluation, and inference using a Kaggle vehicle dataset.

---

## 📂 Dataset
- Vehicle Classification Dataset (Kaggle)
  
---

## ⚙️ Model Details
- Model: YOLOv8 Classification
- Pretrained Weights: `yolov8l-cls.pt`
- Image Size: 224 × 224
- Framework: Ultralytics YOLO

---

## 🚀 Features
- Dataset preparation and class analysis
- Training with data augmentation
- Loss and accuracy visualization
- Inference on unseen test images
- Clean result visualization
